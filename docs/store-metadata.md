## Short Description

Roll, split, and reunite a block across 33 spatial puzzle stages.

## Long Description

CUBIC is a 3D rolling-block puzzle built around deliberate movement and readable spatial challenges. Guide the block into each goal hole, activate switches, control bridges, cross fragile tiles, and coordinate split cubes across a 33-stage classic campaign.

Progress and language preferences are stored locally for quick resume. The first release is offline, contains no advertising or account requirement, and supports touch-first landscape play with sound and vibration feedback in Simplified Chinese, Traditional Chinese, and English.
